# Python_salary_tracker
A Python Object-Oriented Programming (OOP) project that manages employee profiles and salaries 
A clean Python command line application built to track employee profiles, roles and salary details using OOP .

##What I learned & built 
-**Classes & Instances: **Created a reusable 'Employee' blueprint and instantiated individual employee objects.
-**Attributes & Methodes:**Used '__init__, custom getters/setters, and validation logic to manage employee data safely.
-**Clean code staructure:**Separate class definitions from objects  instantiation and program execution.

### How to run 
1- Clone this repository or download 'salary_tracker.py'.
2- Run 'python salary_tracker.py' in your terminal.
